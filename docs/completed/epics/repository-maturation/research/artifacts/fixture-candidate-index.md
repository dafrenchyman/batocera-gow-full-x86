# Test-content research index

Scope: the pinned Batocera 43.1 full-x86 image at upstream revision `155c2d8d304cbb53db52e9479dcf683392821d5c`. This index covers all 253 advertised system/category entries, including utilities, ports and ROM-free cases. It does not establish that all advertised emulators are installed or working.

The [structured catalog](fixture-candidate-catalog.json) owns the full candidate, license scope, prerequisites, primary sources and caveats for every row. This index is its readable view. Each candidate link opens the first primary source; read the full row before selecting content. The [research report](../emulator-fixtures.md) explains methods and the explicitly requested backend findings.

**No candidate is approved for redistribution or verified by execution.** No new fixture/firmware download, build or emulator run occurred. A row is a per-system discovery lead, not proof it works with every advertised backend/core. Source/build leads can still have unresolved rights. External prerequisites can coexist with open application code or possible replacement firmware.

- **Redistribution lead:** A specific content lead has affirmative redistribution terms. This is not complete asset/dependency clearance, a ready-binary guarantee or a compatibility result; some grants impose restrictions.
- **Source/build lead:** Useful source/build lead found, but a complete qualified launchable artifact was not established. Some rows also have unresolved source or asset rights.
- **External restricted prerequisite:** The researched conventional path includes separately copyrighted firmware, operating-system/game data or restricted tooling. Free alternatives may exist but require backend/version qualification; application rights can also remain unresolved.
- **Unresolved:** No sufficiently qualified fixture established in this research. This is not evidence that none exists.
- **Not a ROM case:** A utility/media/launcher category or specifically ROM-free implementation; use a different kind of scenario rather than inventing a cartridge ROM.
