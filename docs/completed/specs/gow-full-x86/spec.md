Reject an unexpected stock `/nix` or `/opt/gow-full-x86` collision rather than overwriting it. Verify before runtime initialization, which necessarily creates transient state.

Use SquashFS superblock sizes, decompressed disk size, closure size, and packaging copies to calculate peak disk needs before extraction. If remaining storage is insufficient, retain the verified download and report the required extra bytes. Do not delete unrelated images or old build directories.
