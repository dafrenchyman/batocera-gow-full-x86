Refuse busy or unknown session/lobby/app-container discovery before effects. Never infer ownership from a name prefix or infer container removal from stop success/lobby absence. Preflight local image availability and document the stock automatic-pull race without automatically provisioning images.

Bound every external call, phase, capture, transfer and teardown. Cleanup has an independent bounded budget, attempts remaining safe actions after independent failures, and never deletes userdata while a lobby/container may still use it. No retries to hide failed assertions. Retain accessible evidence before removal and report unresolved identities safely.

Publish selected sanitized logs, machine-readable results and screenshots to exclusive owner-only `output/integration/<run-id>/` artifacts, with no overwrite/symlink escape, raw session/environment/config dumps, uploads, pruning or automatic commits. Distinguish run behavior, evidence and cleanup acceptance. Extend the testing guide with actual commands and permissions.

## Acceptance criteria

- [x] Missing/invalid remote configuration fails before SSH; local-only operations need no target. Agent/alias and optional identity-path behavior preserve transport protections without reading key contents.
- [x] An authorized native run proves normal frontend readiness and ready transport/worker/pinned final source before stopping the frontend. Diagnostic overrides never alter persistent registration.
- [x] All five existing receiver cases run and report independently: `stock_combo_exit_held_and_pointer_reset`, `stock_context_pointer_button`, `context_switch_without_semantic_leakage`, `held_graceful_source_removal_and_recreation` and `stock_command_once_per_stock_release`. Preserve their exact behavioral contracts; graceful removal is not crash-recovery proof.
- [x] Effective packaged image, entrypoint, UID/GID, isolation, mounts, stock/additive integrity and input prerequisites are inspected before input. Unknown or mismatched evidence closes the gate, and no automatic pull, build, deployment, persistent config change or Wolf restart repairs it.
- [x] Shared-root mismatch, traversal, protected overlap, symlink/replacement and occupied/unowned paths are refused. Real temporary-filesystem tests prove rejected or foreign resources survive cleanup.
- [x] Busy/unknown preflight has no native write/input effects. Late contention/discovery loss prevents later activity, reports interrupted/not-run cases and attempts only owned cleanup without touching unrelated sessions.
- [x] Lifecycle tests cover ordering, finite boundary expiry, partial/late creation, malformed/missing reports, identity changes, signal/timeout, inaccessible targets and independent evidence/cleanup failures. Use deterministic injected time and meaningful process/filesystem tests, not command-text or mock-echo assertions.
- [x] Owned identity is revalidated before destructive operations. Each next case waits for previous owned lobby/container absence. Unresolved startup or failed absence confirmation retains potentially used state and reports incomplete cleanup, never false success.
- [x] Actual frontend/receiver captures and sanitized reports are transferred before source removal to owner-only local artifacts. Capture, publication or transfer failure remains nonpassing and cannot suppress cleanup. Reports expose phase/deadline, ownership, evidence, cleanup and isolation limits without secrets.
- [x] Native qualification records actual image/source identities, chosen finite budgets and observed capability/recovery limits. Host tests are not native proof. The testing guide documents exercised commands, opt-in behavior, effects, recovery and explicit artifact removal.
