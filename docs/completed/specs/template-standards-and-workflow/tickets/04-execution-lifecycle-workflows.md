## What to build

Provide local single-ticket execution, whole-spec coordination, linked non-nested epic planning, shared completion/archival, and truthful topic-organized current documentation. Execution preserves permanent identities, observed acceptance/progress, blockers, exact resume points, pre-code plan review, and post-verification review. Only input-ready, condition-permitted work starts; independent non-conflicting work may run in parallel. Reassess each dependent of Unnecessary work rather than blanket-unblock or cancel it. Retain conclusive negative research as Done and false conditional work as Unnecessary without reporting rejected implementation as delivered.

Wayfinder preserves capabilities/backlog/shared decisions, supports standalone specs, and separates planning readiness from delivery. Child specs follow the same exploration/to-spec contract. Complete verifies distinct spec/epic outcomes, preserves whole folders, repairs incoming/outgoing references, and archives with disposition. Its reachable current-state reference supports direct updates and completion review of substantive added/changed/removed behavior, removing obsolete claims rather than documenting plans as implementation.

Keep the current checkout by default and remove automatic commits, mandatory isolation/integration, resets, tracker closure, and hosted PR steps. Git isolation, commits, and system actions require explicit permission. Resolve missing legacy skill calls through reachable instructions while preserving review/research intent. Exercise graph transitions, unresolved/false conditions, multiple dependent reassessments, refusal gates, fixture folder moves, archival/link repair, integrated epic outcomes, and current-topic updates. Run all-files hooks and remove fixtures. Retire old definitions in ticket 06; real template-spec completion is outside this ticket.
